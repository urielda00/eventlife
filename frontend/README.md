# Event Planning Platform - Frontend

A modern frontend application for a collaborative event planning platform, built with React and Vite, with a focus on responsive UI, smooth user flows, and seamless backend integration.

## Overview

The frontend of Event Planning Platform provides the client-side experience for users to browse, create, manage, and interact with events through a clean and dynamic interface.  
It was built to support real application flows such as authentication, event participation, navigation between pages, and interactive event management features.

## Features

- Responsive event management interface
- Authentication flow integration
- Event browsing and event details pages
- Join and leave event interactions
- Dynamic client-side routing
- API integration for real-time data handling
- Reusable component-based architecture
- User feedback with notifications and interactive UI behavior

## Tech Stack

- React 19
- Vite
- React Router DOM
- TanStack React Query
- Axios
- Amazon Cognito Identity JS
- Styled Components
- Framer Motion
- React Toastify
- React Icons
- Date-fns

## Focus Areas

- Component-based frontend architecture
- Responsive and interactive user experience
- Authentication and protected flows
- API state management
- Scalable code organization
- Smooth UI transitions and usability

## Notes

This project represents the frontend side of a collaborative full-stack event planning system.  
It emphasizes clean structure, modern React development practices, secure user flow integration, and a polished user experience connected to backend services.
